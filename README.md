# Robotic Gripper Design (SolidWorks)

## Overview
This project shows a **Robotic Gripper Design** created using SolidWorks. The gripper is a mechanical assembly used to pick and hold objects. It is driven using a servo motor and a gear-link mechanism.

## Design Description
The gripper consists of multiple links connected using mates in SolidWorks. The motion is transferred from the servo motor to the fingers using gears and connecting links, allowing opening and closing of the gripper.

## Components Used
- Gripper links (left and right fingers)
- Connecting links
- Gear mechanism
- Base structure
- Servo motor (SG90 model)

## Working
When the servo motor rotates, it transfers motion through the gear system. This motion moves the connecting links, which causes the gripper fingers to open or close.

## Assembly Details
The assembly uses different SolidWorks mates like:
- Concentric mates for rotation
- Coincident mates for fixing parts
- Tangent mates for contact surfaces
- Gear mates for motion transfer
- Limit angle mates to control movement range
